# 📊 Student Performance Analysis using Python & Power BI

## 📌 Overview
This project focuses on analyzing student performance using Python and visualizing insights through Power BI dashboards.

It automates data cleaning, performance calculation, and reporting to help teachers identify weak and top-performing students efficiently.

---

## 🎯 Objectives
- Automate student performance analysis
- Reduce manual calculation errors
- Store structured data using SQLite
- Visualize insights using Power BI dashboards

---

## 🛠️ Tech Stack
- Python (Pandas, NumPy)
- SQLite (Database)
- Power BI (Visualization)
- GitHub (Version Control)

---

## ⚙️ Project Workflow

CSV Data → Python Processing → SQLite Database → Power BI Dashboard
